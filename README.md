# PixelPerfekt

Landing page for **Digital Tasbih**, a minimal tasbih counter with collectible themes, streaks and achievements, by PixelPerfekt.

- Website: https://pixelperfekt.ca
- Android: [Digital Tasbih on Google Play](https://play.google.com/store/apps/details?id=com.pixelperfekt.digitaltasbih)
- iOS: coming soon

## About this repo

A static site built with plain HTML, CSS and JavaScript. There is no build step and there are no dependencies. It is hosted on GitHub Pages, deployed from `main`, and served at the custom domain set in `CNAME`.

| File | Purpose |
| --- | --- |
| `index.html` | Page content and sections |
| `styles.css` | Layout, typography and theme tokens |
| `main.js` | Scroll-driven animation, parallax and the pinned themes section |
| `beads.js` | Canvas renderers for the nine bead themes, ported from the app |
| `assets/` | Screenshots and demo video |
